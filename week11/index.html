🧪 一、实验目的

  • 学习 PyBullet 机器人仿真环境搭建方法
  • 实现四足机器人（A1 / Laikago）的基础 trot 步态控制
  • 理解机器人步态生成（gait generation）基本原理
  • 掌握逆运动学（IK）在腿部控制中的应用
  • 学习机器人姿态稳定控制（roll / pitch correction）方法
  • 调试并优化机器人在仿真中的稳定行走能力

🖥️ 二、实验环境

  • 操作系统：Ubuntu 20.04 / WSL2
  • Python版本：3.10
  • 仿真平台：PyBullet
  • 机器人模型：A1 / Laikago URDF
  • 数值计算库：NumPy
  • 图形界面：PyBullet GUI

🚀 三、实验步骤

1️⃣ 启动 PyBullet 仿真环境


p.connect(p.GUI)

2️⃣ 加载四足机器人模型


robot = p.loadURDF(
    "a1/a1.urdf",
    [0, 0, 0.35],
    p.getQuaternionFromEuler([0, 0, 0])

3️⃣ 关节结构解析


for i in range(p.getNumJoints(robot)):
    info = p.getJointInfo(robot, i)
    print(i, info[1].decode(), info[2])

4️⃣ trot 步态生成


phase = 2 * np.pi * freq * t
  • FR + RL：同相
  • FL + RR：反相

5️⃣ 腿部运动轨迹（IK）


x = step_length * sin(phase)
z = step_height * sin(phase)

6️⃣ 姿态稳定控制


roll, pitch = getBaseOrientation()

roll_correction = -0.8 * roll
pitch_correction = -0.8 * pitch
  • 防止侧翻
  • 抑制姿态漂移
  • 提高动态稳定性

7️⃣ 统一关节控制


p.setJointMotorControlArray(
    robot,
    jointIndices,
    p.POSITION_CONTROL,
    targetPositions=angles,
    forces=[200]*len(joints),
    positionGains=[0.25]*len(joints),
    velocityGains=[1.0]*len(joints)
)

8️⃣ 仿真循环运行


while True:
    controller.step(t)

  • ✔ 机器人可以短时间维持行走
  • ✔ 加入姿态控制后显著减少翻倒

🎯 七、实验总结

成功实现四足机器人 trot 步态控制， 并加入姿态稳定控制系统。

实验表明：

  • 单纯 IK 无法保证稳定
  • 必须加入身体姿态反馈
  • PD 控制对平衡非常重要
  • trot 本质是相位协调 + 平衡控制
