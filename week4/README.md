# 💻 ROS2 控制命令

## 发布速度命令

```bash id="t4g92h"
ros2 topic pub /turtle1/cmd_vel geometry_msgs/msg/Twist \
"{linear: {x: 2.0}, angular: {z: 1.0}}"
```

# 📐 运动学公式

机器人圆周运动关系：

```text id="7d3r5x"
v = r × ω
```

其中：

* v：线速度（linear velocity）
* r：圆半径（radius）
* ω：角速度（angular velocity）

# 💡 核心知识

## Twist 消息

ROS2 中用于机器人速度控制的重要消息类型。

---

## linear.x

控制机器人前进速度。

---

## angular.z

控制机器人旋转速度。

---

# ⚠️ 问题与解决

## 问题

机器人运动轨迹不够平滑。

---

## 原因

线速度与角速度比例不合理。

---

## 解决方法

通过调整 `linear.x` 与 `angular.z` 参数比例，使机器人保持稳定圆周运动。
