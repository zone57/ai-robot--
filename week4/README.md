# 💻 ROS2 控制命令

## 发布速度命令

```bash
ros2 topic pub /turtle1/cmd_vel geometry_msgs/msg/Twist \
"{linear: {x: 2.0}, angular: {z: 1.0}}"
```

# 💡 核心知识

## Twist 消息

ROS2 中用于速度控制的消息类型。

## linear.x

控制机器人前进速度。

## angular.z

控制机器人旋转速度。

---

# ⚠️ 问题与解决

## 问题

机器人轨迹不圆。

## 原因

线速度与角速度比例不正确。

## 解决方法

调整 linear.x 与 angular.z 参数比例。
