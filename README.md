本项目学习并实践了 PPO（Proximal Policy Optimization）强化学习算法，用于训练四足机器人稳定行走。

主要内容包括：

- 状态（State）
- 动作（Action）
- 奖励函数（Reward）
- 策略优化（Policy Optimization）
